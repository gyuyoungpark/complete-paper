# Scripts

Twenty Python 3 scripts. The seventeen for text need only the standard library; the three for figures need matplotlib and numpy. Each part file names the scripts it runs, with the command. The scripts read LaTeX; for a Word manuscript, run them on the reading copy that `docx_to_tex.py` makes.

Run every command from the user's project folder, where the manuscript and `paper-state/` are, and call the script by its path in the skill's directory: `python <skill-dir>/scripts/audit.py main.tex --brief paper-state/brief.md`. In the part files, `scripts/...` means that path, and every other path is relative to the project folder. Run a script with `--help` before its first use.

The scripts find problems; read the flagged lines before reporting them.

- `brief_check.py`: the brief part's check: missing or unfilled fields, a RESULT that is too long or carries words of praise, an evidence kind outside the list, key numbers without unit or source, one quantity with two values, evidence rows that are not ready; with `--tex`, key numbers that the manuscript does not quote. Run `python scripts/brief_check.py --help`.
- `abstract_stats.py`: sentences, words, characters and words per sentence for an abstract, with link words (possible extra clauses) and reference words listed for review; checks the sentence limit and the word or character cap. Run `python scripts/abstract_stats.py --help`.
- `eq_refs.py`: unresolved references, duplicate labels, equation numbers typed by hand, numbered displays without a label, and equation labels never cited, across all files given. A main text and a supplement linked with the xr package (`\externaldocument[S-]{supplement}`) are read as two documents. It does not follow `\input`, so pass every file. Run `python scripts/eq_refs.py --help`.
- `supp_check.py`: how the main text uses its supplement: the size of both parts with ratios, every callout with its place and target against the budget, items cited nowhere or unreachable, candidates for the data package, and one style across both files; writes `suppmap.md` with `--ledger`. Run `python scripts/supp_check.py --help`.
- `cite_order.py`: every figure, table and panel with its first citation and the number of citations; uncited items, first citations out of order, uncited panels, paragraphs that open by pointing at a display item, numbers typed by hand. Run `python scripts/cite_order.py --help`.
- `table_check.py`: the form of every table: caption present and on the venue's side, rules, units in the heading, one precision per column, alignment, empty cells, size. Run `python scripts/table_check.py --help`.
- `methods_check.py`: writes the reproducibility checklist `repro.md` for the kinds of work in the paper, then checks it against the manuscript: rows without a place, places that do not exist, words standing where a value should be, software without version. Run `python scripts/methods_check.py --help`.
- `caption_check.py`: every caption with its word count, plus words from the captions part's watch-list (trend, outcome, interpretation, evaluation), filler openers and colours named without a line style or marker, for review; checks a word cap. Run `python scripts/caption_check.py --help`.
- `overlap_check.py`: sentences of one text (for example the conclusion) that repeat sentences of others (the abstract, the introduction), by a shared run of words or by shared content words. Plain text in. Run `python scripts/overlap_check.py --help`.
- `audit_tex.py`: checks a LaTeX manuscript for citation order, figure, table and equation reference order (ground rule 12; figure and table numbers typed as text, such as "Fig. 2", count as citations), equations cited before they are displayed, orphans, abbreviation first use (abstract, body and supplement separately), abstract numbers missing from the body, direct questions, leftover TODO markers and `[CITE: …]` placeholders, limitation sentences outside the Results (ground rule 10), passive voice and activity verbs for our own work (ground rule 11), colons, semicolons and dashes in running text (ground rule 14), the gap described as an absence (ground rule 10), machine tone and a roadmap of the paper (first principle 1, rule 15), earlier work described as a fault (rule 10), word counts, and titles or annotations in plotting code. Run `python scripts/audit_tex.py --help`.
- `prose_lint.py`: the prose part's profile: sentence and paragraph lengths per section and the hits of machine tone by category; with `--compare`, every number, citation, label and formula that an edit changed. Run `python scripts/prose_lint.py --help`.
- `reverse_outline.py`: the first sentence of every paragraph, section by section, with one-sentence paragraphs, section openings that point back and additive openers marked for review; the evaluation of ground rule 15. Run `python scripts/reverse_outline.py --help`.
- `ref_check.py`: the bibliography part's check. Offline: citations without an entry, entries never cited, duplicates, leftover `[CITE: ...]` placeholders, incomplete or malformed entries, large citation groups, year spread and most frequent authors. With `--online`: every DOI and arXiv number resolved and compared with the record, retractions and published versions reported, and a `refcheck.md` ledger with `--ledger`. Run `python scripts/ref_check.py --help`.
- `verify_refs.py`: an earlier, smaller check that each reference exists, through Crossref for DOIs and arXiv for arXiv IDs, and that authors, year and title or volume match. Needs network access. `ref_check.py` covers it; prefer `ref_check.py`.
- `audit.py`: the audit part's runner. It runs the script of every part on the final files, the house rules of `audit_tex.py` included, adds cross-checks (placeholders, the compile log, numbers of the abstract and the conclusion, required statements, initials, limits) and writes one report, `audit.md`. Run `python scripts/audit.py --help`.
- `submit_check.py`: the submit part's check: missing, unused and misnamed files, line numbers, anonymization, arXiv rules, plain-text title and abstract for the forms; with `--pack`, a clean copy of what is sent, with checksums. Run `python scripts/submit_check.py --help`.
- `docx_to_tex.py`: a LaTeX reading copy of a Word manuscript for the other scripts: superscript citations become `\cite`, the numbered reference list `thebibliography`, Heading styles and short bold lines become sections, numbered equation tables become labeled equations, "Fig. N |" legends become figure floats, and Extended Data legends are kept apart from the main figures. It prints what it read and what it could not. Check every finding against the Word text. Run `python scripts/docx_to_tex.py --help`.
- `fig_style.py`: one figure style for one paper: final size in millimetres, fonts, the colour-blind-safe palette, panel labels at one offset, labels on curves, and the encoding table read from `figstyle.md`. Copied beside the paper's plotting scripts and imported by them.
- `schematic3d.py`: device schematics drawn by code in one parallel projection (boxes, layer stacks, cylinders, prisms such as a Hall bar, arrows, notes, a coordinate triad), in the same figure as the data panels.
- `fig_lint.py`: runs the plotting scripts and measures each rendered figure: overlaps, colours with two meanings or that merge for colour-vision deficiency, alignment, text sizes, typeface of symbols, colour maps, final size and file format; across figures, one colour per meaning. Run `python scripts/fig_lint.py --help`.
